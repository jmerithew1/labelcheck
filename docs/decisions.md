## 2026-08-11 — highlight accuracy fix + mockup-fidelity pass (owner-reported defects)

Root cause of misplaced highlights: OCR coordinates were normalized against text-block extents instead of true image dimensions (every box shifted by the label's margin fraction); truth boxes from the generator measured full-width block divs instead of rendered glyphs; and the matcher required the FIRST token to anchor (decorative display fonts forced band fallbacks). Fixed all three; added generator-emitted ground-truth boxes and a repeatable accuracy harness — **exact-layer accuracy 55.4% → 94.3%** (center-contained, IoU ≥ 0.5), gate ≥90% enforced by `scripts/highlight-accuracy.ts`. Fidelity pass to the owner's mockups: single check is a standalone card (no sidebar — mockup 1), batch keeps the shell (mockup 2); result states implemented per mockup screens 2–5 including auto-highlighted issues, simultaneous multi-region highlighting, row→label connector lines, captioned zoom controls, View full size, color-coded batch summaries, Choose-files dropzone, pagination arrows; batch detail panel uses a stacked compact layout. **Rejected alternatives**: keeping viewport-based columns in the detail panel (crushed the label to a sliver); anchoring highlights on rotated images (coordinates don't survive rotation — highlights hide instead, honest over clever).
